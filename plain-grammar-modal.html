大白话语法 · 第 4 篇

「能」「可以」「应该」「必须」——
你中文里早就分得清清楚楚

适合：搞懂了前三篇的钥匙逻辑，想继续往前推进的人

能 / 会 → can 能力 · 技能
可以 → may / can 许可 · 允许
应该 → should 建议 · 义务
必须 / 得 → must 强制 · 必要

前三篇我们聊了「动作本身长什么样」——它什么时候发生、是不是在发生、做完了没有。这些是对动作的描述。

但还有一种东西，不是描述动作，而是表达你对动作的态度：「这事我能做」「这事应该做」「这事必须做」。中文怎么切割这种「态度」，英文就怎么对应。不是背情态动词表，是你中文里早把这些态度分好了——你只需要把每个态度词，对号入座到一个英文形式上。

1

「能」「会」→ can

中文用「能」表达你有这个能力，用「会」表达你通过练习获得了这个技能。英文一个 can 全接住。

我能游泳身体有这个能力
→
I can swim.can + 动词原形（swim，不是 swims）
她会说英语习得的技能，不是天生的
→
She can speak English.不管主语是谁，can 永远 can，不加 s
你能帮我吗？问对方有没有这个能力/意愿
→
Can you help me?can 提到最前面就是问句
can 是铁公鸡——后面动词永远是原形。管你主语是谁。I can swim / She can swim / They can swim。没有 cans，没有 swimming。想起第一篇钥匙3（will）也是这个规律——所有情态动词后面，动词一律光着身子出来，不加任何东西。这是本篇的超级福利：四条钥匙共用一条底层规则。
2

「可以」→ may / can

中文「可以」问的是「允不允许」——不是你能不能做到，是别人让不让你做。英文日常用 can，正式场合用 may。

我可以坐这儿吗？请求许可，不是问自己能不能坐
→
Can I sit here?日常口语 can 足够
你可以走了我允许你离开
→
You can go now.
不可以停车不允许——禁止
→
You cannot park here.cannot = can not，禁止语气
can 身兼两职：能力和许可。「我能游泳」和「我可以游泳」中文分开，英文都是 can——上下文区别。就像中文「打」可以打人也可以打电话，场景说了算。may 是 can 的「穿西装版本」：May I sit here? 比你老板还客气。日常用 can 没人觉得不礼貌。
3

「应该」→ should

中文「应该」「该」是给别人（或自己）一个建议、一个软性义务——不是强制，但你觉得这样对。英文 should 一一对应。

你应该多喝水建议，为你好
→
You should drink more water.should + 原形 drink
我不该吃那么多后悔了，自我批评
→
I shouldn't eat so much.shouldn't = should not
他应该快到了推测，不是给建议
→
He should be here soon.should 也管合理推测
should 有两张脸：建议 + 推测。「你应该休息」是建议。「他应该到了」是推测——你根据经验判断差不多该到了。中文也是同一个「应该」，英文也是同一个 should。不需要换词。
4

「必须」「得」→ must / have to

中文「必须」没得商量，「得（děi）」是口头版必须。英文 must 主观感觉必须，have to 外部压力必须——但日常两者经常混用。

我必须完成这个没得商量，自己给自己压力
→
I must finish this.must + 原形 finish
我得去上班了外部要求——不上班扣钱
→
I have to go to work.口语里 have to 比 must 更常用
你不用着急没必要，不是禁止
→
You don't have to rush.don't have to = 不需要，≠ 不准
「不用」和「不准」——中文分得清，英文也一样。「你不用来」= You don't have to come（不需要）。「你不准来」= You mustn't come（禁止）。don't have to 和 mustn't 是完全两码事。中文从来没把「不用」理解成「不准」——英文同理，别搞混。

四条钥匙一条命：后面接的动词永远是原形

这是本篇最爽的结论——和前两篇时态篇完全不同的爽感。

中文钥匙英文后面接什么例句
能 / 会can动词原形I can swim.
可以may / can动词原形You may go.
应该should动词原形You should rest.
必须 / 得must / have to动词原形I must go.
对比时态篇：时态要操心动词变形（walk→walks→walked），情态动词后面——什么都不用变。can swim，不是 can swims。should go，不是 should went。must finish，不是 must finished。情态动词自己扛了所有语法标记，后面的动词永远裸奔。这是你学到现在最轻松的一篇。

试试这四把钥匙

点击翻转看答案，第5、6题是陷阱

1. 我能帮你点击翻转
I can help you.「能」→ can + 原形 help
2. 我可以进来吗？点击翻转
Can I come in?「可以」请求许可 → can 提前
3. 你应该去看医生点击翻转
You should see a doctor.「应该」→ should + 原形 see
4. 我必须现在走点击翻转
I must go now.「必须」→ must + 原形 go
5. 你不用带伞点击翻转
You don't have to bring an umbrella.「不用」= 不需要，不是 mustn't（不准）
6. 他昨天能来点击翻转
He could come yesterday.「能」在过去 → could（不是 can）

这四把钥匙的边界

本篇四把钥匙覆盖了日常对话里 90% 以上的情态表达：「能/会→can」「可以→may/can」「应该→should」「必须/得→must/have to」。每把钥匙后面跟动词原形——这是全篇最硬的规律。

但中文有两个东西本篇故意没展开：

1. 过去的能力——「那时候我能...」。can 变成 could：When I was a kid, I could climb trees.（小时候我能爬树。）could 是 can 的「过去版本」——把今天的能力往回拨到过去。

2. 委婉——「能不能...」「可不可以...」。中文加「能不能」把语气变软，英文用 could/would 同理：Could you help me? 比 Can you help me? 更软。这是中国人和英国人想到一块去了——加一两个语气词，距离感就出来了。

这两个后续单独成篇。现在先用这四把基础钥匙——日常聊天够用了。

作业：用「能」「可以」「应该」「必须」各造两个跟自己生活有关的句子。别写 He can swim——写你自己今天真的说了的、或者想说的。
