大白话语法 · 第 3 篇

「已经」和「过」——
一把 have done 搞定两个中文高频词

适合：搞懂了前两篇的五把钥匙，想继续往下走的人

前两篇讲了五把钥匙：四把管「事情的整体」（每天 / 了 / 会 / 不没），一把管「正在发生」（be + -ing）。但还有一种情况没覆盖：你说「我已经吃过了」「我去过北京」「还没做完」——这些中文里的「已经」「过」「还没」，英文怎么接？

答案还是一把钥匙：have（变色龙 has）+ 动词尾巴贴 ed（少数动词用特殊形式，比如 go→gone）。这把钥匙管的不是「什么时候做」，而是「做完了没有」「有没有这个经历」。

「已经...了」→ have/has + done

中文用「已经」说一件事做完了、结果现在还有效。英文用 have/has + 动词过去分词，一个意思。

我已经吃饭了动作完成，现在不饿
→
I have already eaten.have + eaten（eat 的过去分词）
她已经走了现在人不在了
→
She has already left.has + left（她 → has）
他们已经到家了复数主语 → have
→
They have already arrived home.have + arrived（规则动词直接加 -ed）
have 是变色龙，跟上篇 be 一个道理「我」配 have，「一个人/东西」配 has，「不止一个」配 have。口语里 have/has 经常缩成 've/'s：I've eaten. She's left. They've arrived. 念起来不费劲。

「过」→ have/has + done（同一把钥匙，换个场景）

中文加一个「过」字，问的是「你的人生履历里有没有这一条」。英文不换钥匙——还是 have/has + done。

你去过上海吗？问经历，不关心什么时候去的
→
Have you been to Shanghai?go 的过去分词是 gone，表示经历用 been
我吃过臭豆腐这辈子吃过，有这段经历
→
I have eaten stinky tofu.同 have + done，换场景不换形式
他没看过这本书人生履历里缺这一条
→
He hasn't read this book.hasn't = has not 的缩写
「已经」和「过」用同一把钥匙？是的。中文分两个字：「已经」强调做完，「过」强调经历。但英文不区分——都用 have + done。你不用纠结该用哪个英文时态，只要中文里有「已经」或「过」，英文统统 have + done 接住。

「还没」→ haven't/hasn't + done

中文「还没」说的是：预期中应该发生/完成的事，现在还没。英文 haven't/hasn't + done，后面常跟 yet。

我还没看完在看，但没结束，预期会看完
→
I haven't finished yet.haven't = have not
她还没回我发了消息，在等回复
→
She hasn't replied to me yet.hasn't + replied
他们还没决定在考虑，没定下来
→
They haven't decided yet.
haven't 后面跟 yet？不是必须，但很常见。yet 就像中文的「还」——「还没」= haven't ... yet。放在句尾就行。如果没说「还」，yet 可以省略——说 I haven't finished 也行。

刹车：什么时候用 -ed，什么时候用 have done？

中文的「了」是个坑。它可以配「昨天」（过去某个时间），也可以配「已经」（强调完成）。英文必须分清楚。

中文英文为什么
我昨天吃了寿司I ate sushi yesterday.有「昨天」→ 用过去式 -ed
我已经吃了寿司I have already eaten sushi.「已经」强调完成 → 用 have done
我上周去了北京I went to Beijing last week.有「上周」→ 用过去式
我去过北京I have been to Beijing.说经历，没具体时间 → 用 have done
怎么判断？看有没有「时间标签」。句子里有明确的时间词（昨天/上周/去年/刚刚那一刻）→ 用第一篇的 -ed 钥匙。只说「做了没」「有没有这个经历」→ 用本篇的 have done 钥匙。两把钥匙各管各的，不混用。

试试这把钥匙

点击翻转看答案，第五题是陷阱

1. 我已经做完了点击翻转
I've already finished.「已经」→ have + finished
2. 你去过北京吗？点击翻转
Have you been to Beijing?「过」→ have been（经历用 been）
3. 她还没来点击翻转
She hasn't come yet.「还没」→ hasn't + come
4. 他们已经到了点击翻转
They've already arrived.复数 → have（缩成 've），already 放中间
5. 我上周去了北京点击翻转
I went to Beijing last week.有「上周」→ 用过去式 went！不是 have been
6. 你看过这部电影吗？点击翻转
Have you seen this movie?「过」问经历 → have seen

这把钥匙的边界

have + done 覆盖了「已经做完」「有过的经历」「还没发生」三大场景，日常对话够用了。但记住：句子里有具体时间词（昨天/上周/去年）→ 用 -ed，不是 have done。这是本篇和第一篇之间的分工——两把钥匙不抢活。

另外，有些动词的过去分词不是简单加 -ed——go 变成 gone，eat 变成 eaten，see 变成 seen。这些不规则的得另外记。但别怕，常用的一百来个，日常说来说去也就二三十个。多读多看，自然记住。

作业：用「已经做了」「去过/做过」「还没做」三个场景，各造两个跟自己生活有关的句子。别写 He has been to London——写你自己真的去过的地方。
