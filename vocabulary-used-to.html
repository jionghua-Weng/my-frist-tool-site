used to / be used to / get used to：三个"习惯"的区别与用法

发布于 2026-05-14  |  分类：词汇辨析

这三个短语长得太像了——都有 used to，但意思完全不同。更坑的是，它们的语法结构也不一样。很多学习者在这三个短语上反复出错。本文帮你一次理清。

1. used to + 动词原形 — "过去常常（现在不做了）"

used to do 表示过去的习惯动作或状态，强调现在已经不这样了。它只有过去式，没有现在式。否定式是 didn't use to，疑问式是 Did...use to?

I used to smoke, but I quit last year.
我以前抽烟，但去年戒了。（现在不抽了。）
She used to live in Shanghai.
她以前住在上海。（现在不住了。）
There used to be a park here. Now it's a mall.
这里以前有个公园，现在是一座商场。
I didn't use to like coffee, but now I love it.
我以前不喜欢咖啡，但现在很爱喝。

2. be used to + 名词/动名词 — "习惯于（已经习惯了）"

be used to 表示"已经适应/习惯了某事"，是一种已经建立的状态。这里的 to 是介词，所以后面接名词或动名词（-ing），不是动词原形。be 可以根据时态变化（was/were used to, is/are used to）。

I am used to the noise now. It doesn't bother me.
我现在已经习惯这个噪音了。不影响我。
She is used to waking up early.
她习惯早起。（早就是一个习惯了。）
He wasn't used to the cold weather at first.
他一开始不适应这种寒冷的天气。

核心判断：be used to + doing（习惯做某事），不是加 do。很多人错写成 "I am used to wake up early"——这是错的，必须用 waking。

3. get used to + 名词/动名词 — "逐渐适应（从不习惯到习惯的过程）"

get used to 表示"从不习惯到习惯的转变过程"，强调的是变化。to 同样是介词，后面接名词或动名词。

It took me a while to get used to driving on the left.
我花了一段时间才适应靠左行驶。
Don't worry — you'll get used to it.
别担心——你会慢慢习惯的。
I'm still getting used to my new job.
我还在适应新工作。（正在进行中的适应过程。）

三者核心区别对比

短语结构含义时间性
used toused to + do过去常常做（现在不做）过去
be used tobe used to + doing已经习惯了现在状态
get used toget used to + doing逐渐适应变化过程

常见错误

错误1：be used to 后面跟了动词原形

✗ I am used to get up early. → ✓ I am used to getting up early.
这里的 to 是介词，必须接动名词。

错误2：把"正在适应"说成 be used to

✗ I am used to the new system. (如果是刚刚开始接触) → ✓ I'm getting used to the new system.
已经适应用 be used to；还在适应中用 get used to。

错误3：混淆 used to 和 be used to 的否定形式

I didn't use to like it. (used to 的否定)
我以前不喜欢它。
I am not used to it yet. (be used to 的否定)
我还不习惯它。
记忆口诀

used to do — 过去常做（现在不了），后面跟动词原形。
be used to doing — 已经习惯，后面跟动名词，是已成的状态。
get used to doing — 正在适应中，描述一个变化的过程。
