# 大白话语法 · 系列生产规范

站点：easyeng.club（英语研习社）。本 skill 管三件事：写作方法论、版权红线、例句审核。三者缺一不可，写完必须逐条过审核清单。

## 一、系列定位

- 读者：零基础 / 初级 / 被语法术语劝退过的人
- 主张：你不需要学新东西，你需要把中文里早就会的语感，接到英文的形式上
- 文件名：`plain-grammar-<主题>.html`（如 plain-grammar-tenses.html）
- 样例文章：`plain-grammar-preview.html`（时态四钥匙，风格基准，随时对照）

## 二、核心方法论（骨架）

每篇文章 = 若干把「钥匙」。一把钥匙 = 一个中文里已有的语感/字词 → 对应英文的一个形式。

固定叙事链，每把钥匙内部按此顺序：
1. **中文你早就会**：指出读者从小就在用的中文习惯（"你说'两个人'从不说'二个人'"）
2. **英文只是换了形式**：给出映射（了 → 动词贴 -ed）
3. **例句 2-4 组**：en + zh 对照，必须贴日常生活
4. **防坑 key-point**（可选）：这个映射会在哪里失灵，提前打补丁

文章整体结构：
- 开场：从中文现象切入（禁止从"英语语法很难"切入）
- 钥匙分节（2-4 把，超过 4 把拆成两篇）
- 自测题：`<details class="quiz">` 折叠，5-6 道中译英，其中至少 1 道陷阱题
- 边界说明：明说这套方法覆盖不了什么，互链语法魔典/语法精讲对应文章承接
- 相关文章 related 区 3 条

## 三、写作语气

- 大白话、短句、口语节奏。念出来像人话，不像教材
- 全文禁用术语：一般现在时、第三人称单数、过去分词、不定式、宾语从句等语法学名词。唯一例外：结尾"边界"节可点名并链接站内体系化文章
- 类比只帮记忆，不冒充语言学结论。涉及"中文没时态"这类议题收着说（中文不给动词变形，但「了/没」早就在分时间——"你不缺时态感"），不喊"谎言""骗局"
- 作业式收尾：让读者用自己的生活各造 3 句（"写你妈几点起床，别写 Tom plays football"）

## 四、版权红线（源头：「零件英语」闲鱼商业产品）

理念和语言事实可以用，**以下表达一律禁止出现**：
- "第X刀 / 三刀 / 四刀" 命名
- "偏旁变体"（水→氵）类比不规则动词 → 咱们用**大写数字类比**（发票「壹佰元」，壹=一，went=go，认脸不背表）
- 突然/忽然、"为"字 这两个元语言例子 → 咱们用 **二/两**（"两个人"不说"二个人"）、**的/地/得**
- "中文没有过去式是谎言/骗了几代学生" 句式
- 「零件式」「零件英语」字样、其原文任何整句
新类比/新例子拿不准时：问 CC，不要蒙。

## 五、例句审核清单（写完逐条过，一条不过不交稿）

1. **动词变形拼写**：fly→flies（辅音+y 变 ies）、watch→watches、go→goes。逐词核对，禁止 flys 类错误
2. **中英信息对齐**：中文有"昨天/明天/每天"，英文必须译出（他昨天打球了 → He played basketball **yesterday**）
3. **不展示非法裸形式**：不把 "She play" 当独立句子展示。变形演示统一用箭头：play → played
4. **搭配地道**：母语者优先说法（I'll lend you a pen 而非 I lend a pen to you；on horseback）。拿不准就换句子
5. **简化不失真**："了"≠一律过去（"明天吃了饭再走"）；didn't（翻篇）vs haven't（牵扯现在）边界必须留口子
6. **变形只干一次**：will / doesn't / didn't 在场，后面动词回原形。每篇至少一道陷阱题考这个
7. **人审后置**：复杂语法点（从句、非谓语、冠词细节）错误率高——写完标注"待 CC 审例句"，不得直接宣布可上线

## 六、页面技术规范

- 骨架用本 skill 目录 `template.html`，含系列专属样式：key-tag 钥匙牌 / pair-table 对照表 / details.quiz 自测 / preview-banner
- **预览阶段**：保留 `<meta name="robots" content="noindex">` + 预览横幅，不挂 AdSense/gtag/百度统计
- **上线阶段**（CC 明确说上线才做）：去 noindex 和横幅；从站内最新已上线文章（如 grammar-tenses.html）复制公共头尾——canonical/OG/JSON-LD/AdSense/gtag/百度统计/_siteIndex 搜索/TTS 点读脚本/备案 footer；板块归属、进导航、sitemap、百度推送均听 CC 指令
- 例句一律 `<div class="example"><div class="en">…</div><div class="zh">…</div></div>`，TTS 点读脚本自动挂按钮
- 写完自检：标签配对、花括号平衡（python 脚本），`start ""` 打开浏览器给 CC 看
